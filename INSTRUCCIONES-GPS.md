# Prueba de GPS

1. Abre la app con Live Server o GitHub Pages.
2. Entra a un cliente y pulsa **Guardar ubicación**.
3. Autoriza el permiso del navegador.
4. Comprueba que aparezca **Ubicación guardada**.
5. Pulsa **Ir al cliente** para abrir Google Maps.
6. En Rutas, selecciona un día y pulsa **Abrir ruta en Google Maps**.

La app no muestra latitud ni longitud.
