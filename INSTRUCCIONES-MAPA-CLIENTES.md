# Mapa de clientes (administrador)

1. Inicia sesión con una cuenta administradora.
2. Abre el menú superior ☰.
3. Selecciona **Mapa de clientes**.
4. Cada cliente con ubicación GPS guardada aparecerá con un pin.
5. Pulsa un pin para abrir la ficha del cliente o iniciar navegación.

Los vendedores no pueden ver esta sección. El mapa usa Leaflet y teselas de OpenStreetMap, por lo que requiere conexión a internet.
